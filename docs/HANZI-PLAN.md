# Hanzi Tangle — 汉字版玩法设计方案

> 状态：设计文档 v1.0（2026-10-21）
> 定位：Tangle Words（英文版）的姊妹产品，面向中文市场的每日汉字拼字游戏

---

## 1. 核心创意

Tiled Words 的"旋转字母"在汉字上不成立（汉字旋转后无意义）。
真正的翻译不是"把字旋转"，而是**把字拆开**：

> **英文版：让字母回到正确的位置**
> **汉字版：让部件拼成正确的字，让字回到正确的位置**

玩家操作的是**偏旁部件砖块**（氵、青、日、月、木、林…），目标是拼出词语矩阵中的每一个字。

这天然成立，因为：
- **形声字占汉字 80%+**，几乎都是"部件 + 部件"（清=氵+青）
- 中文词语横排、竖排皆可读（竖排是中文正统方向）→ crossword 骨架直接可用
- **交叉格无冲突**（见 §5，这是本方案最妙的结构优势）

## 2. 玩法规则（一图流）

```
       横向词条 ──────────►
        ┌───┬───┬───┬───┐
  纵    │ 氵 │ 青 │    │    │   ← 格子 = 一个字，两侧是"部件槽"
  向    │ 左 │ 右 │    │    │      (左右结构字；上下结构第二期)
  词    ├───┼───┼───┼───┤
  条    │ 木 │    │    │    │
   │    ├───┼───┼───┼───┤
   ▼    │    │    │    │    │
        └───┴───┴───┴───┘

托盘（打乱的部件砖块）：
  [氵] [木] [青] [日] [月] [氵] [土] [寸] ...
```

**规则（3 条）：**
1. 每个目标字由 1-2 个部件组成。拖部件进格子的**左槽或右槽**
2. 左右槽齐 → 自动组字 → 比对目标字：对则锁定（变绿、显示完整字），错则红闪弹回
3. 所有格子（横向词 + 纵向词，交叉共享）拼齐 → 通关

**帮助机制（沿用英文版骨架）：**
- 点线索高亮对应词条
- 每个格子显示拼音+释义提示（"qīng · 纯净透明"）
- Reveal ×3：自动填一个格子
- 🔀 洗牌 / ↺ 重置 / ⏱ 计时 / 🔥 streak / 存档 / 归档日历 / 暗色模式——全部复用英文版

## 3. 关键机制设计

| 机制 | 设计 |
|---|---|
| **部件槽** | 左右结构字：格子左右 40% 各一个槽（拖入高亮）；上下结构字（二期）：上下槽 |
| **部件变体** | 部件在不同位置有形变：水→氵、手→扌、心→忄、犬→犭、言→讠、衣→衤… 维护一张"变体映射表"（约 60-80 个常见偏旁），砖块显示变体形态，拼出即标准字形 |
| **同部件复用** | "河""湖""海"都有氵 → 托盘多个氵砖块，任意一个都能放（比英文版按 tile id 精确匹配更宽容，手感和操作负担都好） |
| **防呆** | 拖入错误槽位（如把"氵"拖进需要"木"的格）→ 红闪弹回（复用英文版反馈系统） |
| **Hint** | 拼音 + 释义双提示，默认显示拼音，点开看释义——不给免费答案 |
| **Reveal** | 显示该格完整字 + 自动归位两个部件 |
| **镜像机关（三期彩蛋）** | 部分字/部件镜像后是另一字：人↔入、士↔干（近似）… 砖块偶发"镜像态"，点击翻转复原。数量少，作彩蛋不作主机关 |

## 4. 每日题目形态

- **网格**：8 列 × 6 行（复用英文版骨架，移动端已验证）
- **词条**：3-4 个横向词 + 3-4 个纵向词，交叉成矩阵
- **用词**：2-4 字常用词（晴空、河水、森林、灯火、湖泊、柳树…）
- **主题化**（复用 THEMES 机制）：自然、天气、动物、颜色、家庭、食物…每日常见 4-5 词归属主题
- **难度**：基础题全部左右结构字（覆盖常用字 60%+）；上下结构二期加入后按比例混合

## 5. 生成器：为什么这个方案的技术风险最低

英文 crossword 生成器最难的是**交叉字母匹配**（ACROSS 第 3 字母必须等于 DOWN 第 2 字母，需要模式索引反复回溯）。

汉字版有个结构性的偷懒机会：

> **交叉格共享的是"整字"，不是"笔画"**

横向词与纵向词在交叉格必须是**同一个字**（例如横词"河流"的"河"与纵词"河水"的"河"）。同一个字 = 同样的两个部件。**部件零冲突，无需回溯匹配。**

生成流程：
1. 选主题 → 选横向词 + 纵向词（词库按"共享字"预索引，交叉点用共享字连接）
2. 每个字拆部件（查表，12,000 常用字 × 部件拆分库，一期只收录 800 个常用左右结构字）
3. 部件打散进托盘（含随机冗余：部分部件多放几个混淆项）

**复杂度比英文版还低**，确定性生成、历史回放、归档日历全部免费继承。

## 6. 字库与词库建设

| 库 | 内容 | 规模（一期） |
|---|---|---|
| **部件拆分表** | 常用左右结构字 → 两个部件（清→氵+青） | 800 字 |
| **变体映射表** | 水→氵 等偏旁形态变体 | 60-80 条 |
| **词库** | 2-4 字常用词，按主题分类 | 400 词（够一年 365 题轮换） |
| **交叉索引** | 词间共享字索引（选词用） | 派生 |

数据来源：公开的汉字拆分数据（如 CJK 部首数据、开源拆字库）人工校对一期 800 字即可开跑，成本可控。

## 7. 差异化与市场

**为什么这是 Tiled Words 做不到的：**
- Tiled Words 是英文团队，汉字拆字文化门槛它跨不过来
- 中文 daily puzzle 网页游戏目前**没有知名产品**（中文填字 App 都是老式下载游戏，无每日/无分享传播形态）

**三个真实卖点：**
1. **教育属性**——"玩着学会形声字"。部编版小学语文二年级就教"青字家族"（清晴情请），我们的玩法天然是教具。**家长愿意让孩子玩**，这是传播的核弹
2. **微信生态**——分享图 + 链接即开即玩，微信群（家长群/班级群）传播链路顺畅，无需下载
3. **视觉仪式感**——通关分享卡用大字号展示今日组出的字（"晴 河 森 灯"），比英文字母更有视觉冲击和文化认同

**变现路径（国内习惯）：** 免费每日题 + 会员解锁全部历史题/无广告 + 教育机构合作（形声字练习产品）。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 部件拆分存在学术争议（"江"的"工"是声旁但形似） | 一期只收录无争议的常用形声字（氵+青、木+林级别），争议字不进库 |
| 偏旁渲染：系统字体缺偏旁变体 | 变体映射表 + 内置字体（NotoSansCJK 已有）+ 偏旁用 SVG 兜底 |
| 词库交叉索引不足导致生成失败 | 词库预索引共享字 + 生成器回溯降级为"无交叉的独立词排布"（横向词区 + 纵向词区分离布局） |
| 起步字库 800 字显得窄 | 一期每日题只用其中 300 高频字轮换，观感足够；二期扩到 2,000 字 |
